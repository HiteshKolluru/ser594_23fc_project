Description:   
This project looks at how music expresses emotions through different genres like pop, rock, rap, and country. By analyzing song lyrics, we can discover how these genres reflect feelings such as happiness, sadness, anger, or excitement. Since lyrics often tell stories, studying them can help us understand how each genre connects with certain emotions.

Intellectual Merit: This project aims to identify emotion within song lyrics.

Data Sourcing: Genius API for songs and their lyrics
